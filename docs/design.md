# Design

- Une seule colonne de texte, d'une largeur confortable à la lecture,
  centrée.
- Typographie système, sans police téléchargée.
- Un thème clair et un thème sombre, choisis selon la préférence du
  système du lecteur.
- Blocs de code sur fond distinct, avec défilement horizontal plutôt
  que retour à la ligne ; couleurs de coloration lisibles dans les
  deux thèmes.
- Lisible sur téléphone sans défilement horizontal de la page ; une
  image n'est jamais plus large que la colonne.
