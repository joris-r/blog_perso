# Dev43

This project follows the Dev43 process. Before any work, load the
`dev43:core` skill and follow it.

If the `dev43:core` skill is missing, ask the human to install the Dev43
plugin from https://github.com/joris-r/dev43
(marketplace `joris-r/dev43`, plugin `dev43@dev43`).


# Project instructions

## Contenu

Le dossier `content/` est le contenu du blog : il est écrit par
l'auteur seul.

- Ne crée, ne modifie, ne déplace et ne supprime aucun fichier sous
  `content/`, quelle que soit la demande ou la tâche.
- Tu peux lire `content/` et proposer des textes ou des corrections
  dans la conversation ; l'auteur les recopie lui-même.
- Les tests n'utilisent pas `content/` : ils ont leurs propres
  dossiers de contenu sous `tests/fixtures/`.
