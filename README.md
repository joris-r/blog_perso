# Blog

Blog personnel de billets sur le développement logiciel,
publié sur https://jirm.eu/ avec Eleventy v3.

- `content/` : le contenu, écrit par l'auteur seul.
- Le reste : le logiciel qui construit le site.

Commandes (Node.js 24) :

```sh
npm install
npm run build   # construit le site dans _site/, vérifie la forme du contenu
npm run serve   # serveur local avec rechargement
npm test        # tests du logiciel
```

La spécification est dans [docs/](docs/README.md).
